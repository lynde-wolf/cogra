# CogRA logo

The wordmark and icon, set in TeX Gyre Schola Bold with a drawn psi, and worn
with cogra's own scan look.

| file | use |
|---|---|
| `cogra-wordmark.svg` | the wordmark, clean vector |
| `cogra-wordmark-scan-600.png` | the wordmark, archival scan (used at the top of the README) |
| `cogra-icon.svg` | the square icon, clean vector |
| `cogra-icon-scan-512.png` | the icon, archival scan: avatars, docs sidebars |
| `favicon-32.png` | browser tab icon |
| `cogra-social-1280x640.png` | GitHub social preview (Settings, Social preview) |
